Brian Wilson Modern Portfolio Website

Files:
- index.html: Home page
- portfolio.html: Portfolio and experience page
- contact.html: Contact page with static email form
- assets/styles.css: Website styling
- assets/main.js: Mobile menu and contact form script
- assets/profile.png: Profile image extracted from the original portfolio

How to publish:
Upload all files and the assets folder to your website hosting root. The home page must stay named index.html.

Contact form note:
The form is static and opens the visitor email app addressed to brianwilson0625@gmail.com. For direct website submissions without opening email, connect the form to a service such as Formspree, Netlify Forms, or a backend endpoint.
